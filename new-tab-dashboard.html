New Tab Dashboard

Your new tab, but useful. Tasks, notes, a focus timer, favourite links and a daily quote, all on one calm page. No account, no tracking: everything stays in your browser.

Download v1.0.0 (ZIP) Chrome Web Store: coming soon Support on Ko-fi

What it does

  • Tasks with priorities. Drag a task onto the timer to start a focus session for it.
  • Pomodoro timer with work, short-break and long-break modes.
  • Notes that autosave as you type.
  • Favourite links, plus quick-launch cards for local HTML dashboards.
  • Rotating quotes, built-in backgrounds, or your own image.
  • Drag, minimise and pin cards to arrange the page your way.
  • Export and import a backup of everything, free.

Your data stays yours

Local-first

Everything you enter is saved in your browser with chrome.storage.local. The extension has no server, no account and no analytics, and asks for one permission only: storage. Read the privacy policy.

Works where Chrome works

Windows, Mac, Linux and ChromeOS

Any desktop Chrome, and Chromium browsers such as Edge, Brave and Vivaldi. Chrome on phones and tablets doesn't support extensions.

Install

Install it now (about a minute)

Until the Chrome Web Store listing is live, you can add it by hand. It is the same extension and the source is public on GitHub.

  1. Download the ZIP and extract it to a permanent folder. Chrome runs the extension from that folder, so don't move or delete it afterwards.
  2. In Chrome, open chrome://extensions and switch on Developer mode (top right).
  3. Choose Load unpacked and select the extracted folder, the one that contains manifest.json.
  4. Open a new tab. If Chrome asks about the new tab change, accept it.

Good to know

  • Local file links and dashboards need Allow access to file URLs, switched on under the extension's Details.
  • Wait for notes to show "Saved locally" before closing a tab, and use Settings > Export backup before updating or moving anything.
  • To update, export a backup, close dashboard tabs, extract the new ZIP over the same folder, then reload the extension on chrome://extensions.
  • Edit in one window at a time. Two visible windows edited together can overwrite each other.
  • Removing the extension deletes its saved data, so export a backup first.
